# Сайт школы № 548 «Царицыно»

Многостраничный адаптивный сайт школы № 548 «Царицыно» в согласованной цветовой концепции: оранжевый, белый, серый и чёрный.

В проекте представлены корпуса школы, образовательные направления, новости, документы, формы обратной связи и встроенный ИИ-помощник «Бук». Помощник отвечает на частые вопросы о поступлении и использует подготовленную базу знаний по положениям школы.

## Что реализовано

- адаптивная версия для компьютеров и мобильных устройств;
- информация о пяти корпусах школы;
- образовательные направления: инженерное, социально-экономическое, медиакласс, медицинское, ИТ, художественное и китайское;
- русская и английская версии страниц;
- поиск по основным разделам сайта;
- формы с сохранением обращений в PostgreSQL;
- ИИ-помощник «Бук» с базой частых вопросов и документов;
- серверная часть на Node.js;
- подготовленная конфигурация для размещения на Vercel.

## Структура проекта

- `site/` — страницы сайта, стили, скрипты, изображения и страницы корпусов;
- `api/` — серверные обработчики форм и ИИ-помощника;
- `lib/` — логика помощника и работа с базой знаний;
- `data/` — подготовленные данные для ответов помощника;
- `db/` — схема базы данных PostgreSQL;
- `research/` — исходные документы и собранные материалы;
- `photo-review/` — материалы по отбору фотографий;
- `qa/` — результаты визуальной проверки сайта;
- `scripts/` — служебные сценарии проверки;
- `server.js` — локальный сервер проекта;
- `PGADMIN.md` — инструкция по работе с базой данных через pgAdmin;
- `REPORT.md` — отчёт по выполненной работе.

## Требования

- Node.js 20 или новее;
- PostgreSQL;
- установленный клиент `psql` для автоматического создания таблиц.

## Запуск на компьютере

1. Установить зависимости:

   ```bash
   npm install
   ```

2. Создать локальный файл настроек:

   ```bash
   cp .env.example .env
   ```

3. Указать в `.env` строку подключения к PostgreSQL в переменной `DATABASE_URL`.

4. Создать таблицы базы данных:

   ```bash
   npm run db:init
   ```

5. Запустить сайт:

   ```bash
   npm start
   ```

6. Открыть в браузере [http://localhost:3000](http://localhost:3000).

## ИИ-помощник

Без ключа OpenAI помощник работает на локальной базе знаний. Для подключения генеративных ответов нужно указать в `.env`:

```env
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-5-mini
```

Ключи и другие секретные данные нельзя добавлять в репозиторий. Файл `.env` уже исключён из Git.
